#Сценарии системного тестирования

## Предусловия
- Приложение развернуто и доступно по адресу `http://localhost:8080/training_center_clean`.
- База данных инициализирована схемой и тестовыми данными.
- Установлен браузер Chrome или Edge.
- Selenium-тесты запускаются через Maven: `mvn -Dtest=training_center.system.WebSystemTest test`.

## Сценарии, покрытые Selenium

1. Открытие главной страницы и проверка основных ссылок навигации.  
Ожидаемый результат: видны ссылки на курсы, преподавателей, обучающихся и организации.

2. Успешное создание организации при корректных данных.  
Ожидаемый результат: переход на список организаций и отображение новой записи.

3. Ошибка при создании организации без названия.  
Ожидаемый результат: форма остается открытой и показывается сообщение об ошибке.

4. Ошибка при создании организации без адреса.  
Ожидаемый результат: форма остается открытой и показывается сообщение об ошибке.

5. Успешное создание обучающегося при корректных данных.  
Ожидаемый результат: переход на список обучающихся и отображение новой записи.

6. Ошибка при создании обучающегося без ФИО.  
Ожидаемый результат: форма остается открытой и показывается сообщение об ошибке.

7. Успешное редактирование обучающегося.  
Ожидаемый результат: переход в карточку обучающегося и отображение обновленного ФИО.

8. Успешное удаление обучающегося.  
Ожидаемый результат: переход на список обучающихся и отсутствие удаленной записи.

9. Успешное создание преподавателя при корректных данных.  
Ожидаемый результат: переход на список преподавателей и отображение новой записи.

10. Ошибка при создании преподавателя без ФИО.  
Ожидаемый результат: форма остается открытой и показывается сообщение об ошибке.

11. Успешное редактирование преподавателя.  
Ожидаемый результат: переход в карточку преподавателя и отображение обновленных данных.

12. Успешное удаление преподавателя.  
Ожидаемый результат: переход на список преподавателей и отсутствие удаленной записи.

13. Успешное создание курса при корректных данных.  
Ожидаемый результат: переход на список курсов и отображение новой записи.

14. Ошибка при создании курса без названия.  
Ожидаемый результат: форма курса остается открытой и показывается сообщение об ошибке.

15. Ошибка при создании курса с некорректной интенсивностью.  
Ожидаемый результат: форма курса остается открытой и показывается сообщение об ошибке.

16. Ошибка при создании курса с некорректной длительностью.  
Ожидаемый результат: форма курса остается открытой и показывается сообщение об ошибке.

17. Успешное редактирование курса.  
Ожидаемый результат: переход в карточку курса и отображение обновленных значений.

18. Успешное удаление курса.  
Ожидаемый результат: переход на список курсов и отсутствие удаленной записи.

19. Успешное добавление обучающегося в курс.  
Ожидаемый результат: переход в карточку курса и отображение обучающегося в блоке участников.

20. Успешное назначение преподавателя на курс.  
Ожидаемый результат: переход в карточку курса и отображение преподавателя в блоке преподавателей.

21. Успешное удаление обучающегося из курса.  
Ожидаемый результат: переход в карточку курса и отсутствие обучающегося в списке.

22. Успешное удаление преподавателя из курса.  
Ожидаемый результат: переход в карточку курса и отсутствие преподавателя в списке.

23. Успешное создание занятия при корректном интервале времени.  
Ожидаемый результат: переход в карточку курса и появление занятия в расписании.

24. Ошибка при создании занятия, если время окончания раньше времени начала.  
Ожидаемый результат: форма занятия остается открытой и показывается сообщение об ошибке.

25. Успешное получение расписания обучающегося за корректный интервал.  
Ожидаемый результат: в расписании отображаются курс и преподаватель созданного занятия.

26. Успешное получение расписания преподавателя за корректный интервал.  
Ожидаемый результат: в расписании отображается курс созданного занятия.

27. Ошибка при запросе расписания обучающегося, если задана только одна граница интервала.  
Ожидаемый результат: показывается сообщение о некорректном интервале.

28. Ошибка при запросе расписания преподавателя, если задана только одна граница интервала.  
Ожидаемый результат: показывается сообщение о некорректном интервале.

- Если приложение не запущено или WebDriver не инициализируется, системные тесты автоматически пропускаются.
